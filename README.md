# scoop-bucket

[Scoop](https://scoop.sh) bucket for [wslim](https://github.com/4riful/wslim).

```powershell
scoop bucket add 4riful https://github.com/4riful/scoop-bucket
scoop install wslim
```

This installs `wslim` (the app, also added to the Start menu) and `wslim-cli` (the command-line version).
